# 风格规范

竖屏 1080×1920，30 fps。口播是白墙真人；讲解画面是深色带光的代码世界；品牌元素是 logo 里那一格蓝色斜方块（蓝窗）。

## 固定不变的

| 项 | 规矩 |
|---|---|
| 蓝窗 = AI | 品牌蓝 #0091FF 的斜方块。画面里 AI 在干活、或者进入讲解世界时用它（`pane` 镜头、`lines` 的网关） |
| 字幕 | 白字粗体，深色半透明圆角底，y = 1505，最宽 960 px。逐字按录音，只改错字 |
| 字体 | 正文 Noto Sans SC；手写 Long Cang（龙藏体）、Zhi Mang Xing（智漫行）。都是 OFL，可商用 |
| 颜色 | 墨黑 `ink` #16191E，品牌蓝 `blue` #0091FF，强调红 `red` #D23C2A。手写批注用墨黑或蓝，重点用红 |
| 深色背景 | `DARK_FRAG`：上深蓝灰到下近黑，淡淡的雾和点阵 |
| 画中画 | 圆角竖向窗（默认 290×350，圆角 34），蓝色光晕，名字标签，下方音量条；跟着人头移动 |
| 证据小窗 | 圆角 22，细亮边，标签“真实后台录屏 / 真实教程录屏”；默认右上角（850, 168, 宽 380）或左下角 |
| 阴影 | 所有窗口、卡片都有柔和投影 |
| 片尾 | 标语逐字打出 + logo；音乐跟着收 |

## 画面怎么选

| 说的内容 | 用什么 |
|---|---|
| 开头钩子、章节标题 | `bigType` 大字放在人身后，人头只压住字的下沿；一屏最多两行 |
| 痛点、吐槽、情绪 | `hand` 手写字、`strike` 划掉、`circle` 圈出来、`people` 小人、`bars` 额度条；都画在人身后，不挡脸和手臂 |
| 原理、连接关系 | `lines` 线稿世界：来源 → 网关（蓝窗）→ 每个人；光点流向 = 数据或钱的流向；角落标“原理示意” |
| 后台数据 | 代码重画真实数字（`numbers`、自定义图），**加** `evidence` 小窗放真实录屏 |
| 教程、代码、AI 做了什么 | `term`：真实原文的代码块，一步一步高亮，拎出放大；加 `evidence` 放真实教程页并高亮对应行 |
| 进入讲解世界 | `pane`：蓝窗在人身后打开，镜头穿进去。每条最多 1–2 次 |
| 关键词、行动号召 | `pill` 标签落下；`chip` 段落角标 |

**总规矩：每个特效讲清一件具体的事。** 同一个版式不要连用太久，换景别（talk 的 `zoom` 1.0 / 1.06 / 1.12）来遮住剪接点。

## 声音

- 人声在最前，响度约 −16 LUFS，峰值 ≤ −1.5 dB。
- BGM 全程铺底，约 −27 LUFS；人说话时侧链压低约 7 dB；前奏只出现一次，主体按小节循环，结尾落在曲子自己的结尾。
- 音效只配看得见的动作：落卡片 `card`、手写 `pen`、点击 `click`、转场 `whoosh`、大字 `slide`、亮起 `switch`、逐个出现 `tick`、打字 `type`。低频 `boom` 全片最多 2 次。

## 隐私清单（每条片子交付前逐屏查）

- 人名（按归属人、成员列表、聊天记录）→ 整列打码
- 余额、账单、密钥、Token、账号页 → 打码或不出现
- 底部对话框、通知、浏览器标签 → 裁掉
- 客户名、客户 logo、工人正脸 → 没有书面授权就不出现
- 重画或模拟的画面 → 标“示意”
