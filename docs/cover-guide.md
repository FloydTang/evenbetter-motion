# 视频封面标准

## 先锁定同系列参考

开工先打开最新、实际采用的同系列封面。至少看一张竖图；做横版时也看一张横图。沿用该系列题头、主副标题、字体和橙色关键词等既有规则。不同账号或系列各自参考。没有现用参考时，先请用户提供，或递交明确标作探索的稿子。

「看懂」日常口播的视觉线索是暖米色纸感、黑色粗标题、烧橙色重点和能讲清当期主题的具象道具或微缩实景。真人、动作和道具一起讲题。旧白黄大字视频日记封面只供历史复现。这些线索用于辨认现行版式；字形以当期参考图为准。

## ImageGen 出图也要保持字体

1. 输入分开给：近期封面是**版式和字体参考**，本条真实帧或授权照片是**人物参考**。有经确认且可用的标题模板或字体时，同时使用。给出精确标题、断行、主副层级和橙色强调词，请 ImageGen 把字体也做成与参考同一套视觉的完整封面。
2. 按成图比字。对照笔画形状和收笔、字面宽窄、字重、字距、行距，以及主标题、关键词和小字的比例。中英版分别检查。只凭参考图片无法认定字体的具体名称，记录视觉基准即可。
3. 字形、排版或错别字有偏差时，用同一张参考重做文字区。需要手动排字时，使用能复现参考字形的已确认模板或有权使用的字体。只生成底图再套通用粗黑体，不能直接交付；若仍对不齐，先作为待确认稿。

## 比例和裁切

- 竖稿 1080×1920（9:16）的居中 3:4 实际可见区是 **y=240–1680**。题头、完整标题、人脸和关键道具都要进这个区域，并给边缘留余量。上下延伸区主要留背景。
- 导出 1080×1440（3:4），和 9:16 的真实居中裁切并排检查。16:9 横封面单独重排，把标题、脸和关键道具放在中间主体区。
- 交付前，用相同宽度（约 320–360 px）并排看新稿、现用参考和 3:4 裁切。核对文字、字体、人物和关键道具。字体不一致或裁切会遮挡关键信息时，先修再交付。封面参考、人物素材和字体文件按各自授权范围保管。
