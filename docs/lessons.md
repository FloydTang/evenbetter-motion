# 踩过的坑

| 现象 | 原因 | 怎么做 |
|---|---|---|
| 听写时间越到后面越不准（3 分钟偏 8 秒） | 整段识别时间戳漂移 | `asr_chunks.py` 用 16 秒窗口、12 秒步长 |
| 重说的地方字幕对到第一遍 | 两遍文字一样 | `episode.json` 的 `sub_fix` 手动指定 |
| 抠像把墙的一角当成人 | 墙面光照模型只看了头顶和两侧 | `wall` 加上实际是墙的区域（比如右下角） |
| 录屏切出来的画面和时间对不上 | 录屏是可变帧率，`ffmpeg -ss` 放在输入前会落到错的帧 | 一律用 `trim` 滤镜（`rec_segment.py` 已经这样做） |
| zsh 里 `$2:end` 变成乱码 | zsh 把 `:e` 当成路径修饰符 | 变量一律写成 `${2}` |
| 渲染报 `could not be decoded` | 抠像还在写某一帧，或者录屏帧不够 | 等 `prep_talk.py` 跑完；录屏片段会自动来回播放 |
| 方形画中画显得呆 | 用户反馈“像个小笨蛋” | 圆角竖向窗口 + 光晕 + 跟随头部 |
| 只放录屏不好看，只放代码画面又不可信 | — | 代码画面做主，录屏做证据小窗 |
| 5 分钟口播没人看完 | — | 剪到 2–3 分钟，只用整句 |
| 无头 Chrome 残留后接管了用户自己的 Chrome | 测试浏览器没关 | `render.mjs` 每次用独立的临时配置并在结束时关掉；自己另开的测试浏览器用完要关 |
| 证据小窗里字看不清 | 小窗只有 380 px 宽 | 小窗的作用是证明“是真实录屏”，数字靠主画面讲清楚 |
| 手写字被画中画挡住 | 位置重叠 | 出样张时专门查这一项 |
